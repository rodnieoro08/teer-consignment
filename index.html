Share with colleagues

There is no Abbott stock app behind this yet. The practical team workflow:

  1. One person keeps the live file (usually you).
  2. Export JSON after a stock check or case.
  3. Drop it in the team Teams / WhatsApp folder.
  4. Everyone else taps Import and the serials merge by serial number.

Optional live URL

If you host the same JSON on a private gist raw URL, SharePoint anonymous link, or JSONBin, everyone can tap Pull.
